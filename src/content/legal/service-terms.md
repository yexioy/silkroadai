## 一、服务定义

1. **本服务**:Silk Road AI 是一个面向开发者的 AI API 聚合网关平台(以下简称"平台"),通过 `ai.silkroadai.io` 等域名为用户提供统一的 OpenAI 兼容接口,聚合调用第三方 AI 大语言模型(包括但不限于 Anthropic、OpenAI、SiliconFlow 旗下模型)。
2. **关键说明**:平台**仅提供模型路由、计费、用户管理等中间层服务**,实际 AI 推理由上游模型提供商完成。**平台不开发、不运营任何 AI 模型,亦不对模型生成的内容负任何责任**。
3. **预付费机制**:用户充值人民币后,平台按汇率换算为内部 quota 额度,API 调用按上游模型实际消耗扣减。

## 二、账户管理

1. 用户注册时需提供真实有效的邮箱地址,该邮箱将作为账户主标识与账单接收地址。
2. **每位自然人或法人实体仅限注册一个账户**,严禁多账号、虚假身份或代他人注册。
3. 用户应妥善保管账户密码及 API Key(`sk-` 开头的访问凭证),**因密码或 API Key 泄露导致的损失由用户自行承担**。
4. 用户可通过 Google / GitHub 等第三方 OAuth 服务登录,登录信息处理详见《隐私政策》。
5. 我们保留以下权利:
    - 因用户违反本条款封禁账户(违反内容详见第四条);
    - 因法律法规、监管要求要求关闭账户;
    - 因长期不活跃(超过 24 个月)且账户余额低于 ¥10 的账户进行清理。

## 三、计费、充值与余额

1. 充值通过易支付聚合支付通道完成,支持支付宝、微信支付等渠道,**结算货币为人民币**。
2. 充值金额按平台公布的汇率(默认 1 USD ≈ ¥7.2,1 USD = 500,000 quota)换算为内部 quota 额度。
3. **API 调用按上游模型计费规则实际扣减 quota**,具体单价以平台公布为准,我们保留根据上游变化调整定价的权利,价格调整通过站内通知告知。
4. **账户余额无失效期限**,但不计息、不可提现、不可转让。
5. 退款相关条件详见《退款政策》。

## 四、使用限制(禁止行为)

用户**不得**通过本服务从事以下行为:

1. **违法内容**:发布、传输、生成涉及恐怖主义、儿童色情、煽动暴力、谣言、诽谤、欺诈、赌博、毒品交易、武器交易、人身攻击等违反所在司法管辖区法律法规的内容。
2. **侵犯第三方权益**:侵犯他人著作权、商标权、专利权、隐私权、姓名权、肖像权等合法权益。
3. **绕过限制**:破解、逆向工程、滥用 API 进行 DDoS 攻击、僵尸网络运营或大规模未经授权的数据爬取。
4. **违反上游模型条款**:Anthropic、OpenAI 等上游服务商的使用条款也适用于通过我们网关的调用。**用户违反上游条款被上游服务商封禁所导致的服务中断由用户自行承担**。
5. **转售本服务**:除非另有书面授权,用户不得将本服务直接或包装后转售给第三方。
6. **滥用试用资源**:通过多账户、虚假身份或脚本批量薅取免费资源、首充优惠等。

我们有权在发现违规行为时**立即暂停或终止账户**,严重情况下保留追究法律责任的权利。

## 五、服务可用性

1. 我们尽力保证服务的稳定性和连续性,但**不承诺 99.x% SLA**。
2. 因下列原因导致的服务中断不视为故障:
    - 上游 AI 模型提供商的故障、政策调整、API 变更或限流;
    - 不可抗力(自然灾害、战争、政府行为等);
    - 计划内的系统维护(将提前通过站内通知告知);

3. 连续 24 小时以上的非计划故障且与上游模型无关的,用户可申请退款,详见《退款政策》。
